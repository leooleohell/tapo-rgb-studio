# Tapo RGB Studio

Десктопное приложение для управления светодиодными лентами TP-Link Tapo под Linux (Ubuntu, Linux Mint, Debian) и Windows.

Программа позволяет управлять подсветкой прямо с компьютера без использования мобильного приложения, поддерживает синхронизацию цветов с монитором (Ambilight) и раздельное управление несколькими зонами освещения.

---

## Возможности

- Быстрый отклик: прямое асинхронное подключение через библиотеку python-kasa без лишних задержек.
- Выбор цвета: интерактивная карта спектра, ручной ввод HEX-кодов и настройка цветовой температуры белого (2500K - 6500K).
- Двухзонное управление: одновременная работа со всеми лентами или раздельная настройка подсветки (например, верх стола и под столом).
- Ambilight: захват изображения с монитора и адаптация подсветки в реальном времени под происходящее на экране.
- Встроенные эффекты: плавная смена цветов, эффект огня, дыхание и мягкое затухание яркости.
- Таймеры: режим помодоро (25/5 мин), таймер автоматического отключения и запуск по расписанию.
- Автопоиск устройств: сканирование локальной сети для автоматического обнаружения лент и их IP-адресов.
- Горячие клавиши: регулировка яркости стрелками и быстрое переключение предустановленных цветов цифровыми клавишами.

## Установка на Linux (Ubuntu / Linux Mint / Debian)

### Вариант 1: Установка готового .deb пакета

1. Скачайте файл tapo-rgb-studio_1.0.0_all.deb из раздела Releases.
2. Установите пакет командой:
```bash
sudo apt install ./tapo-rgb-studio_1.0.0_all.deb
```
3. Установите Python-зависимости:
```bash
pip install customtkinter python-kasa pillow --break-system-packages
```
4. Запустите приложение через системное меню или командой tapo-rgb-studio.

### Вариант 2: Запуск из исходного кода

1. Склонируйте репозиторий:
```bash
git clone https://github.com/ВАШ_НИК/tapo-rgb-studio.git
cd tapo-rgb-studio
```
2. Установите необходимые пакеты:
```bash
pip install -r requirements.txt
```
3. Запустите программу:
```bash
python3 tapo_view.py
```

## Начало работы

1. Откройте вкладку 'Поиск и Сеть'.
2. Укажите логин и пароль от аккаунта TP-Link Tapo (данные сохраняются только локально в файле конфигурации).
3. Запустите сканирование сети — программа найдет подключенные ленты и сохранит их IP-адреса.
